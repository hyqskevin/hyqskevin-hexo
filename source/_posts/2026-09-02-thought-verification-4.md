（上）活动模式，（中）参与者与组织，（下）商业化。本篇（末）讲**宁波怎么落地**——本地化的思想验证领域。

## 一、为什么"不是复制北京"

```text
思想验证领域 = 活动品牌（不限地域）
  - 北京 / 上海 / 杭州 / 宁波 都能做
  - 但每个地方气质不同
  - 不能"复制粘贴"成功模式

宁波气质：
  - 制造业基础（轻工 / 装备 / 新材料）
  - 外贸 + 出海企业多
  - 高校密集（宁大 / 诺丁汉）
  - 务实 + 不浮夸
```

## 二、宁波方案：5 个主理人画像

### 2.1 主理人 1：制造业 AI 应用

```text
背景：本地制造业（汽配 / 模具 / 纺织）
角色：AI + 制造业
特长：把 AI 工具落地到质检 / 排产 / 调度
为什么需要：宁波 80% 制造业缺 AI 人才
```

### 2.2 主理人 2：外贸 + AI

```text
背景：外贸 / 跨境电商老板
角色：出海 + AI
特长：用 AI 做产品文案 / 客服 / 选品
为什么需要：宁波外贸企业 1 万+ 急需 AI
```

### 2.3 主理人 3：独立开发者

```text
背景：自由职业 / 远程 / 出海
角色：技术 + 商业
特长：1 人公司 / 副业探索
为什么需要：宁波 25-35 岁"想做点什么"的人多
```

### 2.4 主理人 4：哲学 / 心理

```text
背景：高校老师 / 心理咨询师
角色：思辨 / 心理
特长：跨界对话 / 引导讨论
为什么需要：社群需要"软"专家
```

### 2.5 主理人 5：设计 / 品牌

```text
背景：本地设计 / 文创
角色：设计 / 表达
特长：把复杂概念视觉化
为什么需要：社群需要"看得见"的内容
```

## 三、宁波 4 个空间候选

| 位置 | 优势 | 劣势 | 适合 |
|---|---|---|---|
| **老外滩** | 文创氛围好 / 咖啡馆多 | 租金高（¥8-15/m²·月）| 沙龙 + 酒会 |
| **鄞州南部** | 年轻白领多 / 交通便利 | 制造业多 | 工作坊 + 讨论 |
| **高新区** | AI 公司聚集 | 商业气氛浓 | 技术分享 + 黑客松 |
| **镇海 / 北仑** | 大学城 / 港口 | 离主城远 | 跨界 + 出海 |

**推荐**：**鄞州南部商务区**（平衡租金 / 人群 / 交通）

## 四、空间设计（200 m²）

## 五、3 个月 MVP 启动

### M1：组队 + 选址

```text
Week 1-2：
  - 找到 5 个主理人（前述画像）
  - 每周 1 次主理人会议
  - 明确活动主题 + 风格

Week 3-4：
  - 选址 + 签租约
  - 装修启动
  - 招募首批社群（30-50 人）
```

### M2：内容试水

```text
Month 2：
  - 每周 1 次沙龙（试 4 场）
  - 1 次大型公开活动（50+ 人）
  - 收集反馈 + 调整

预算：8 万
  - 装修 5 万
  - 押一付三 3 万
  - 活动 1 万
  - 主理人补贴 1 万
```

### M3：常态化

```text
Month 3：
  - 固定每周 1-2 场活动
  - 知识星球上线（¥199 / 年入门）
  - 30+ 付费会员

年底目标：
  - 200 会员
  - 5 主理人
  - 月营收 ¥3 万
  - 盈亏平衡
```

## 七、3 个失败案例

### 7.1 西安某读书会

- 失败原因：主理人离职 → 社群散
- 教训：**主理人稳定性 = 社群稳定性**

### 7.2 武汉某沙龙

- 失败原因：高端化 → 用户少
- 教训：**下沉到用户能消费的价格**

### 7.3 杭州某思想社群

- 失败原因：内容太学术 → 参与者少
- 教训：**学术 + 实用 = 平衡**

## 八、3 个本地启示

### 8.1 宁波可以做什么

- **5-7 个主理人**（覆盖 商业 / 技术 / 心理 / 设计 / 学术）
- **50-200 个付费会员**（第 1 年）
- **季度 1 次大型活动**（年度宁波 AI 思想节）
- **年营收目标 ¥30-50 万**

### 8.2 不要"复制北京"

- 宁波的"制造业 + 外贸"是特色
- 主题设计 = 制造业 + AI + 全球化
- 不要学"哲学小镇"的纯学术路线

### 8.3 关注政策机会

- 宁波"AI 人才补贴"最高 30 万
- 高新区"科创空间租金减免"
- 鄞州"青年人才公寓"
- 用好政策 = 启动期成本降 50%
