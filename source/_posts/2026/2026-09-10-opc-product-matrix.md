## 二、应用 1 · OPC-PMF 评分卡（引擎 1 主推）

> **"5 分钟测出你的 OPC 项目能不能跑通"**——基于 Sean Ellis Test，做成 OPC 行业版本。

### 2.1 对接 OPC 的环节
- **客单价**：1-2 万/次评估
- **频次**：3-5 单/月
- **核心壁垒**：标准化评分标准 + 数据沉淀

### 2.2 技术架构

| 模块 | 技术栈 | 复杂度 |
|---|---|---|
| **问卷引擎** | 腾讯问卷 API / 金数据 + 自建后端 | 🟢 低 |
| **PMF 计算引擎** | Python（Sean Ellis Test + 5 维度评分） | 🟢 低 |
| **报告生成** | Python + Jinja2 + Canvas 模板 | 🟡 中 |
| **数据看板** | Streamlit / Metabase | 🟢 低 |
| **客户案例库** | Notion API + PostgreSQL | 🟢 低 |

### 2.3 核心功能（MVP）

```text
1. 5 个核心问题输入（用户访谈）
   - 你从哪儿知道这个产品的？
   - 上一次用是什么时候？为什么？
   - 如果明天消失，你会怎么样？
   - 你愿意付多少钱？为什么？
   - 你会推荐给谁？为什么？

2. PMF 评分（0-100）
   - Sean Ellis Score：≥40% = PMF
   - 5 维度评分：付费意愿 / 复购率 / 留存 / 推荐意愿 / 客单价

3. 30 页诊断报告（自动生成）
   - 项目现状 / 用户访谈 / PMF 评分 / 改进清单

4. 改进建议（基于观猹标准）
   - 客单价 × 复购率 × 留存三角模型
```

### 2.4 开发排期（30 天）

| 周 | 动作 | 交付物 |
|---|---|---|
| W1 | 设计问卷 + Sean Ellis 算法 | MVP 引擎 |
| W2 | 报告模板（Canva / Notion） | 报告生成器 |
| W3 | 免费给 3 个 OPC 做，迭代 | v1.0 |
| W4 | 接 3 单付费测试 | v1.1 + 案例库 |

## 三、应用 2 · AI 工具栈体检（引擎 1 A1 评估）

> **"扫码测出你的 AI 工具栈健不健康"**——OPC 用的 AI 工具太多太杂，需要体检和优化建议。

### 3.1 对接 OPC 的环节
- **客单价**：1-3 万/次评估
- **频次**：3-5 单/月
- **核心壁垒**：AI 工具栈指纹库 + 优化建议算法

### 3.2 技术架构

| 模块 | 技术栈 | 复杂度 |
|---|---|---|
| **工具栈指纹扫描** | Browser extension / 桌面 agent | 🟡 中 |
| **工具栈数据库** | PostgreSQL（OpenClaw/Cursor/Bolt/N8N 等 200+ 工具） | 🟢 低 |
| **健康度评分** | Python（4 维度：覆盖 / 冗余 / 兼容 / 成本） | 🟡 中 |
| **优化建议生成** | LLM API + 模板库 | 🟢 低 |
| **对比分析** | Next.js 前端 | 🟡 中 |

### 3.3 核心功能（MVP）

```text
1. 工具栈指纹采集
   - Browser extension 自动扫描 OPC 用的工具
   - 或 OPC 手动填写（问卷形式）

2. 健康度评分（0-100）
   - 覆盖度：核心环节是否都有 AI 工具？
   - 冗余度：是否有重复功能？
   - 兼容性：工具间是否能串联？
   - 成本：月费是否合理？

3. 优化建议
   - 推荐补什么工具
   - 推荐砍什么工具
   - 推荐工作流串联（N8N / Make / Dify）
   - 推荐成本优化方案

4. 对标分析
   - 同行业 TOP 10 OPC 的工具栈
```

### 3.4 开发排期（21 天）

| 周 | 动作 | 交付物 |
|---|---|---|
| W1 | 工具栈数据库（200+ 工具） | v0.5 |
| W2 | 健康度评分算法 + 报告 | v1.0 |
| W3 | 免费给 3 个 OPC 做测试 | v1.1 + 案例库 |

## 四、应用 3 · OPC 资源对接平台（引擎 2 核心）

> **"OPC 创业者的资源对接中心"**——把政府/资本/大客户/跨境渠道/同行 OPC 撮合到一起。

### 4.1 对接 OPC 的环节
- **客单价**：年费 999-9999 + GMV 抽佣 5-15% + 大赛陪跑 1-3 万
- **频次**：500 个 OPC 会员 + 20 单/月撮合
- **核心壁垒**：网络效应 + 资源方 BD 能力

### 4.2 技术架构

| 模块 | 技术栈 | 复杂度 |
|---|---|---|
| **会员系统** | Next.js + Supabase Auth | 🟢 低 |
| **资源方管理** | PostgreSQL + Admin Dashboard | 🟢 低 |
| **撮合算法** | 简单标签匹配 + LLM 评分 | 🟡 中 |
| **支付系统** | 微信支付 / 支付宝 | 🟢 低 |
| **微信小程序** | Taro / uni-app | 🟡 中 |
| **聊天系统** | 微信群 + 客服机器人 | 🟢 低 |

### 4.3 核心功能（MVP）

```text
1. OPC 会员注册（付费）
   - 个人 OPC：999 元/年
   - 团队 OPC：9999 元/年

2. 资源方入驻
   - 政府机构（NBOPC 赋能中心）
   - 资本机构（天使 / VC）
   - 大客户（宁波 B 端）
   - 跨境渠道（美博·中东欧）
   - 同行 OPC（互相推荐）

3. 智能撮合
   - OPC 标签：行业 / 阶段 / 需求
   - 资源方标签：类型 / 行业 / 投入
   - 撮合算法：标签匹配 + LLM 评分

4. 案例库 + 知识库
   - 152 家 OPC 入驻项目
   - 成功案例 / 失败案例
   - 政策解读 / 大赛指南
```

## 五、应用 4 · OPC 政策雷达（引擎 2 政府对接）

> **"每天 8:30 推送今天对 OPC 有用的政策"**——甬创9条、杭州/苏州/温州政策实时追踪。

### 5.1 对接 OPC 的环节
- **客单价**：免费拉新 + 转化 OPC 资源对接平台付费
- **频次**：每日推送
- **核心壁垒**：政策源覆盖 + NLP 摘要

### 5.2 技术架构

| 模块 | 技术栈 | 复杂度 |
|---|---|---|
| **政策抓取** | RSS + WebFetch | 🟢 低 |
| **NLP 摘要** | DeepSeek API / 通义千问 | 🟢 低 |
| **推送系统** | 微信公众号 + 邮件 + 微信群机器人 | 🟢 低 |
| **政策匹配** | 标签匹配（行业 / 阶段 / 城市） | 🟢 低 |
| **历史库** | PostgreSQL | 🟢 低 |

### 5.3 核心功能（MVP）

```text
1. 每日 8:30 推送
   - 宁波市政府 / 海曙区 / NBOPC 赋能中心
   - 杭州 / 苏州 / 温州 / 扬州（跨城市）
   - 工信部 / 科技部（国家级）

2. NLP 摘要
   - 自动识别"对 OPC 有用"的政策
   - 解读 + 申报建议

3. 政策匹配
   - 根据 OPC 标签（行业 / 阶段）匹配政策

4. 申报提醒
   - 大赛报名截止提醒
   - 算力补贴申报提醒
   - 人才认定申报提醒
```

### 5.4 开发排期（14 天）

| 周 | 动作 | 交付物 |
|---|---|---|
| W1 | 政策源接入（10 个）+ NLP 摘要 | v0.5 |
| W2 | 推送系统 + 公众号上线 | v1.0 |
