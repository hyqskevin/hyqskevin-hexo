## 一、证书说明

人工智能训练师是 **2020 年由人社部正式纳入《国家职业资格目录》的新职业**，2021 年发布《国家职业技能标准（2021 年版）》。它的官方定义是：

> 使用智能训练软件，在人工智能产品实际使用过程中进行数据库管理、算法参数设置、人机交互设计、性能测试跟踪及辅助作业的人员。

| 等级           | 名称        | 对应职称 | 报考起点（一般）             |
| ------------ | --------- | ---- | -------------------- |
| 五级 / 初级工     | 初级训练师     | —    | 初中毕业即可               |
| **四级 / 中级工** | 中级训练师     | —    | 累计从业 4 年 或 初级证 + 3 年 |
| **三级 / 高级工** | **高级训练师** | 高级工  | 累计从业 6 年 或 中级证 + 3 年 |
| **二级 / 技师**  | **技师**    | 技师   | 取得三级证 + 4 年          |
| 一级 / 高级技师    | 高级技师      | 高级技师 | 取得二级证 + 4 年          |

### 1.1 报考条件

**三级（高级工）—— 满足以下之一：**

- 累计从事本职业工作 **6 年（含）以上**
- 取得本职业四级 / 中级工证书后，累计从事本职业工作 **3 年（含）以上**
- 取得本专业或相关专业的技工院校、技师学院毕业证书（含应届）
- 大专及以上本专业或相关专业毕业证书（含应届）

**二级（技师）—— 满足以下之一：**

- 取得本职业三级 / 高级工证书后，累计从事本职业工作 **4 年（含）以上**
- 取得本职业三级 / 高级工证书的技师学院毕业生，累计从事本职业工作 **3 年（含）以上**
- 硕士研究生及以上本专业或相关专业学历，累计从事本职业工作 **2 年（含）以上**

> **走竞赛通道不需要等报考年限**

## 二、考纲范围介绍

### 2.1 理论部分（三级通用，180题）

> **题型分布**：单选题 140×0.5 + 多选题 20×1 + 判断题 20×0.5 = 100 分
> **两场考试均为三级（高级工）竞赛**——市里最高能评二级（技师）。

| 板块               | 权重       | 考点                                                             |
| ---------------- | -------- | -------------------------------------------------------------- |
| 一、工作组织与管理        | 10%      | 健康安全法规、数据安全原则、AI 伦理合规、任务时间管理                                   |
| 二、沟通与人际交往        | 5%       | 团队协作、结果展示与报告撰写、向非技术人员解释模型效果                                    |
| 三、数据采集/预处理/清洗/标注 | 25%      | 常见数据格式、噪声类型、标注规范、标注一致性                                         |
| 四、模型训练与优化        | 30%      | 监督/无监督学习原理；CNN/RNN/Transformer；PyTorch/TensorFlow；超参调优、正则化、过拟合 |
| 五、Python 编程及效果展示 | 20%      | Python 语法与数据结构、数据可视化库、模型推理脚本、损失曲线、评估报告                         |
| 六、职业道德与安全法规      | 10%      | 数据隐私法律、AI 伦理准则、数据安全管理、隐私保护合规红线                                 |
| **合计**           | **100%** |                                                                |

**市里补充内容**：

- Prompt 工程、RAG 基础、Agent 基础概念、智能体平台操作

### 2.2 实操部分

#### 🅰 鄞州区 —— Python 数据分析 + 模型训练

> **平台**：Python 3.10 + PyTorch 2.12 + Jupyter Notebook + Anaconda 2022.10+ + LabelMe
> **时长**：120 分钟 / 4 个模块
> **总分**：100 分（评价分 30% + 测试分 70%）

| 模块                     | 权重   | 考核内容                                                                                            | 实操工具栈                          |
| ---------------------- | ---- | ----------------------------------------------------------------------------------------------- | ------------------------------ |
| **A 数据采集与预处理**         | 15 分 | ① 原始数据采集整理（5）；② 质量检测 / 识别噪音、缺失值、异常值（5）；③ 数据清洗 + 格式转换 + 质量检测（5）                                  | pandas / NumPy                 |
| **B 人工智能数据集标注**        | 30 分 | ① 图像标注软件操作（10）；② 按规范完成目标类别 + 目标框标注（15）；③ 导出可视化图 + VOC/.xml / YOLO/.txt（5）                       | LabelMe + 标注规范                 |
| **C 人工智能应用模型训练** ★     | 30 分 | ① 导入数据集（5）；② 按要求选模型 + 参数调节完成训练（15）；③ 模型质量评估 + 核心评估参数展示（10）                                      | PyTorch / TensorFlow + sklearn |
| **D 人工智能应用编程及场景建模** ★  | 25 分 | ① 数据导入清洗 + 预处理（标准化 / 划分训练集测试集）（5）；② **基于 PyTorch 加载 ANN 模型完成推理预测**（15）；③ 计算精确率/召回率/F1 + 评估报告（5） | PyTorch + matplotlib           |

> **平台**：LCAgent 智能体搭建平台（教育智能体超市）+ Office
> **时长**：120 分钟 / 3 个模块
> **总分**：100 分（评价分 60% + 测试分 40%）

| 模块 | 权重 | 考核内容 | 实操工具栈 |
|---|---|---|---|
| **模块 1 业务分析** | 25% | ① 业务流程设计（15 评价）；② 业务模块效果优化（10 评价） | Office + 流程图 |
| **模块 2 智能训练** | 35% | ① 数据处理规范制定（15 评价）；② 算法测试（20 评价） | 数据处理工具 + AI 测试工具 |
| **模块 3 智能系统设计** ★ 重头 | 40% | ① 智能系统监控和优化（30 测试）；② 人机交互流程设计（10 测试） | **LCAgent 平台** + Prompt 迭代 |

**样题**：

1. 导入企业经营模拟数据集 `test1.csv`，**启用回归模块开展建模**。选取"部门月度运营投入（invest_hour）"为解释变量预测"部门月度利润（profit）"，构建一元线性回归模型，同时完成核心参数设置。
   - 选取 "部门月度运营投入（invest_hour）"、"市场推广费用（market_cost）" 作为解释变量预测 "部门月度利润（profit）"，构建多元线性回归模型；
   - 开启共线性诊断检验，并输出残差直方图、标准化残差、标准化残差 Q-Q 图，同步确认其余核心参数设置。
   - 运行多元线性回归模型，查看模型核心评估参数：决定系数（R²）、调整后决定系数（Adjusted R²）、回归系数、显著性 P 值、变量共线性、残差分布状态，分析并精炼描述模型拟合效果。

2. 企业希望通过 YOLO 目标检测模型，**对工人工作场景图像中的防护防滑手套、未戴防护防滑手套、防护护目镜、未戴防护护目镜等目标进行自动识别和定位**。
   - 导入赛题图像文件夹中的图像，对 50 张待标注图像中的穿戴装备目标进行矩形框标注，标注时应保证类别选择准确，矩形框尽量贴合目标主体。
   - 对于遮挡严重、目标极小或无法判断类别的目标，可不标注。
   - 检测类别为：1 Gloves（戴防护手套）、2 No-Gloves（未戴防护手套）、3 Goggles（戴护目镜）、4 No-Goggles（未戴护目镜）。
   - 将完成的 50 张图像标注文件的目录截图、第 1 和 25 项标注文件的内容截图整理到赛题文档中。
   - 手动编写模型训练所需的 `data.yaml` 配置文件，确保训练路径、验证路径、检测类别数量、四类目标类别名称等信息配置正确。配置文件编写完成后，将完整内容截图整理到赛题文档中。

3. 企业人力资源部门、行业研究机构需要依托标准化数据集完成全球 AI 岗位薪资、地区分布、技能要求、从业年限等**多维度数据挖掘与可视化分析**。本次实操采用行业公开数据集 `Global_AI_Jobs.csv`，**依托 Python 工具完成数据清洗、数据标准化、特征相关性可视化等流程，输出可用于行业信息展示的标准化分析报表与可视化图表**。

4. **模块 1：政务服务智能问答业务流程设计和模块效果优化** —— 某电子政务场景，需要为政务服务智能问答提供可用数据并训练模型。
5. **模块 2：网页应用生成** —— 通过**迭代式 Prompt 工程**，让 AI 生成可直接运行的 HTML/CSS/JavaScript 网页应用。
   - 提交：`index.html`（可直接运行）+ `Prompt迭代记录.docx`（每轮 Prompt + AI 输出摘要 + 优化说明）+ `Prompt设计说明.docx`
6. **模块 3：数据库运维操作智能体搭建** —— 根据运维任务清单，完成数据库/数据表创建、SQL 查询编写与优化、备份恢复。
   - 提交：`数据库运维_导出数据.csv`
   - 同分条款：实际赛题很可能包含"**数据分析智能体搭建**"或"**线上知识库检索智能体搭建**"

#### 案例：政务热线智能问答 Agent

**题目**（模拟）：某区政务热线日均接入 5000 通电话，希望用 AI Agent 实现 80% 自动答复率。请给出完整方案。

**拆解思路**：

```text
业务目标：80% 自动答复率 ↓
    ↓
子任务 1：意图识别（用户问什么？）
    ├── 模型：BERT 文本分类（39 个委办局分类）
    ├── 评估：意图识别准确率 ≥ 95%
    └── 数据：10 万通历史工单 + 人工标注
    ↓
子任务 2：知识库检索（相关政策是什么？）
    ├── 切片：政策文件按章节切，500–1000 字/块
    ├── 检索：BGE-M3 向量化 + BM25 混合检索
    ├── 重排：BGE-Reranker 精排 Top 5
    └── 评估：召回率 ≥ 90%，R@5 ≥ 85%
    ↓
子任务 3：答复生成（怎么回答？）
    ├── Prompt：角色(政务专员) + 任务(回答市民咨询) + 约束(准确、简洁、引政策) + 格式(分段+引用)
    ├── 模型：Qwen2.5-14B（本地部署）
    ├── Loop：生成 → 事实核查 → 改写 → 输出
    └── 评估：人工评估准确率 / LLM-as-Judge / 市民满意度
    ↓
子任务 4：转人工触发（什么情况下转人工？）
    ├── 规则：置信度 < 0.7 / 涉及投诉 / 涉及个人案件
    ├── 工单系统对接：自动创建工单 + 分配坐席
    └── 评估：转人工率 20%，转人工准确率 ≥ 95%
    ↓
整体评估闭环（Harness）：
    ├── 离线评估：1000 条测试集，各子任务指标
    ├── 在线 A/B：新旧版本对比
    ├── 用户反馈：满意度评分 + 投诉率
    └── 每周回归：防止数据漂移
```

**这个拆解就是 Loop & Harness 的核心**——它不是一个模型，是一个**多个子 Agent + 评估闭环**的系统。市考就是要看你**有没有这种工程化思维**。
