## 一、核心概念回顾

### 1.1 MCP（模型上下文协议）

MCP 是 AI 与外部工具通信的标准化协议。在「设计转代码」场景里，它的核心作用是：把设计工具的图层结构、样式属性、组件关系等结构化数据传递给 Trae、Cursor、通义灵码等 AI 编程工具，让 AI 准确理解设计意图并生成高还原度代码。

### 1.2 核心需求场景

- 设计稿/原型 → 结构化数据（MCP）→ AI → 前端代码（React/Vue/Taro/小程序等）
- 兼容国内 AI 工具（Trae、通义灵码），无需科学上网
- 支持多原型并行设计、团队协作
- 兼顾成本与功能完整性

## 四、关键实操指南

### 4.1 MasterGo → Pixso 迁移步骤

```text
1. 打开 MasterGo 免费版设计文件，选择「文件 → 导出为 → Figma 格式」
2. 登录 Pixso 免费版，新建项目 →「导入 → 上传 Figma 文件」
3. 等待解析完成（复杂文件 1-2 分钟），调整组件/样式变量
4. 保存为 Pixso 自有格式，即可通过 MCP 读取数据
```

### 4.2 Pixso + Trae MCP 配置步骤

```text
1. 打开 Pixso 客户端（v2.2.0+），左上角菜单 →「Pixso MCP → 打开本地 MCP 服务器」
2. 复制 MCP 服务器链接（如 http://localhost:3000）
3. 打开 Trae IDE →「设置 → MCP → 添加自定义 Server」，粘贴链接并保存
4. 在 Trae 中选择「Pixso 设计文件」，输入提示词生成代码
```

### 4.3 墨刀 MCP 启动命令

```bash
# 安装并启动墨刀 MCP
npx @modao-mcp/modao-proto-mcp --token=<YOUR_TOKEN>
# Token 获取：墨刀工作台 → AI 页面 → 头像菜单 → API Token
```

## 五、注意事项

1. **文件格式选择**：优先导出 Figma 格式（Pixso/MasterGo 兼容度最高），避免 PNG（仅图片，无结构化数据）
2. **代码生成优化**：复杂交互逻辑需手动补充，MCP 主要解决 UI 还原问题
3. **Taro 适配**：选择支持 Taro 的 AI 工具（Trae、通义灵码），提示词明确「Taro 组件库映射」
4. **数据安全**：企业级场景优先选择支持私有化部署的版本（MasterGo 企业版 / Pixso 企业版）
