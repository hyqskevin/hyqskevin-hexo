## 一、5 大收入源

### 1.1 会员订阅（核心 / 60%）

```text
模式：知识星球 / 飞书知识库
  - 入门版：¥99-199 / 年（碎片化知识）
  - 标准版：¥399-799 / 年（系统化内容 + 群）
  - 高端版：¥1999-4999 / 年（1 对 1 + 定制）

3 个价格段用户：
  - 探索者：选 ¥199（求内容）
  - 转换者：选 ¥799（求系统 + 群）
  - 创业者：选 ¥2999（求 1 对 1）

年营收（5:3:2 比例 × 1000 用户）：
  - 500 × ¥199 = ¥100,000
  - 300 × ¥799 = ¥240,000
  - 200 × ¥2999 = ¥600,000
合计：¥940,000
```

### 1.2 课程 / 工作坊（25%）

```text
周末工作坊：1-2 天，¥500-2000 / 人
线上训练营：4-6 周，¥1999-4999 / 人
企业内训：定制，¥30,000-200,000 / 场

年营收：¥300,000-500,000
```

### 1.3 大型活动（10%）

```text
年度思想节：1-2 天，¥200-1000 / 人，200-1000 人
  - 单场营收 ¥100,000-500,000
学术论坛：半天，免费（品牌收益）
校友返校日：免费，捐赠 ¥10,000+ / 人

年营收：¥200,000
```

### 1.4 咨询 / 1 对 1（3%）

```text
个人咨询：¥2000-5000 / 小时
企业顾问：¥30,000-100,000 / 月
专家网络：按问题收费

年营收：¥50,000-100,000
```

### 1.5 内容出版（2%）

```text
白皮书：¥99-499 / 份
书：¥50-100 / 本
课程视频：¥99-499 / 套

年营收：¥30,000-50,000
```

## 二、3 个定价策略

### 2.1 免费策略（拉新）

```text
免费内容：
  - 公众号文章（每周 1-2 篇）
  - 公开活动（每季度 1 次）
  - 试读章节（课程前 30%）

目的：
  - 建立权威
  - 拉新用户
  - 转化为付费

成本：主理人时间
收入：0（间接）
```

### 2.2 订阅策略（主力）

```text
核心模式：年费会员
  - 持续收入（不像单次课一次性）
  - 用户粘性高（订阅 6 月 + 的用户续订率 60-80%）
  - 可预测收入（年度规划更稳）

价格段：
  - 入门 ¥199：内容 + 群
  - 标准 ¥799：内容 + 群 + 工作坊
  - 高端 ¥2999：1 对 1 咨询 + 优先参与活动

会员价值：
  - 探索者：¥199 已足够
  - 转换者：¥799 性价比最高
  - 创业者：¥2999 物超所值
```

### 2.3 单次消费（补充）

```text
场景：用户没买会员但有特定需求
  - 单次活动门票（¥50-200）
  - 单次工作坊（¥500-2000）
  - 单次咨询（¥2000-5000 / 小时）

价值：满足"不订阅但有需要"的用户
```

## 三、规模化悖论的 3 个解法

规模越大 → 社群感越弱 → 老用户离开 → 文化稀释。

### 3.1 解法 1：分层服务

```text
大众层：免费 / 低价（公众号 + 公开活动）
  ↓
爱好者层：¥199-799 会员（社群 + 内容）
  ↓
核心层：¥2999 高端会员（1 对 1 + 活动）
  ↓
校友层：老会员（终身福利）

每层服务不同，**避免"一刀切"**导致老用户被冷落。
```

### 3.2 解法 2：分布式品牌

```text
不是 1 个"思想验证领域"覆盖所有用户
而是 5-10 个"主题分支"：
  - 哲学分支
  - 商业分支
  - 技术分支
  - 创业分支
  - 心理分支

每分支独立社群 + 主理人
但共享"母品牌" + 校友网络
```

### 3.3 解法 3：内容沉淀 + 校友网络

```text
不是"做新活动"拉新
而是"沉淀已有内容"：
  - 100 场沙龙 → 录播
  - 1000 次咨询 → 案例库
  - 10000 校友 → 永久网络

**内容 + 校友 = 长期护城河**。
不需要持续做新事，而是把过去的事反复使用。
```

## 五、3 个失败案例

### 5.1 混沌大学

- **失败原因**：课程标准化 + 师资流失
- **教训**：**师资质量是核心**，没有 IP 的平台必死

### 5.2 三联中读

- **失败原因**：高定价 + 学术化 + 用户基数小
- **教训**：**学术 ≠ 商业**，要找平衡点

### 5.3 樊登读书分会

- **挑战**：总部强 → 分会弱
- **教训**：**分会要有独立运营权**，否则主理人没动力

## 六、3 个本地启示（宁波）

### 6.1 宁波可以做什么

```text
- 5-10 个主理人（覆盖商业 / 哲学 / 技术 / 心理）
- 50-200 个付费会员
- 季度 1 次大型活动
- 年营收目标 ¥30-50 万（Y1）
```

### 6.2 不要"复制北京"

- 宁波有"制造业 + 外贸"特色
- 知识传播 + 制造业应用 = 差异化
- 避开学界派的纯学术路线

### 6.3 关注政策机会

- 宁波人社局有"AI 人才补贴"（最高 30 万）
- 高新区有"科创空间租金减免"
- 用好政策 = 启动期成本降 50%
