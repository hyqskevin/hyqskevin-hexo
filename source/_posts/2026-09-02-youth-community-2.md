（上）篇写了三家的共性 + C2B 模式。本篇（中）讲三家**各自怎么运转**——跳海的打酒师 / 北辰的课程 / 706 的共居。

## 一、跳海酒馆："打酒师 + 分布式"

### 1.1 模式

```text
"让顾客当服务员"
  顾客（打酒师）→ 服务新顾客
  主理人（店长）→ 管 5-10 个打酒师
  总部 → 管主理人 + 选址 + 品牌
```

**具体流程**：
- 新顾客到店 → 老顾客（打酒师）接待
- 打酒师拿 5-10% 提成 + 免费酒水
- 主理人（店长）拿 5% + 招聘新人

### 1.2 财务模型

| 项 | 占比 / 数值 |
|---|---|
| **客单价** | 80-150 元 / 人 |
| **人力成本** | 15%（行业平均 30%） |
| **食材成本** | 25% |
| **租金** | 20% |
| **毛利** | 70% |
| **净利润** | 25% |

**核心**：人力成本砍半 → 毛利拉到 70%（行业 50% 是常态）

### 1.3 扩张方式

- "分布式" = 标准化单店模型 + 本地主理人
- 主理人拿 10-20% 店股份 + 5% 月利润
- 总部只管：选址 / 品牌 / 培训
- 2018 第一家店 → 2024 30+ 店

**风险**：
- 主理人出走开店 → 品牌稀释
- 城市差异大 → 标准化难
- 现金流好但社区感弱

## 二、北辰青年："课程包年 + 活动"

### 2.1 模式

```text
"卖青年成长解决方案"
  学员（年费会员）→ 课程 + 活动 + 社群
  讲师（特邀）→ 课程生产
  总部 → 课程设计 + 城市分社 + 活动运营
```

### 2.2 财务模型

| 项 | 数值 |
|---|---|
| **会员费** | 999-2999 元 / 年 |
| **课程单价** | 99-499 元 / 课 |
| **活动单价** | 50-200 元 / 人 |
| **年留存率** | 50-60% |
| **客单价** | 1500-2500 元 / 人 |
| **毛利** | 60% |

### 2.3 扩张方式

- "中央厨房 + 城市分社"模式
- 总部出课程 / 品牌 / 培训
- 城市分社做活动 + 落地
- 全国 10+ 城市分社

**风险**：
- 课程质量依赖讲师 → 难复制
- 城市分社强依赖本地主理人
- 课程产品生命周期短（半年热度）

## 三、706 青年空间："物理共居 + 知识社群"

### 3.1 模式

```text
"让人找到同类"
  共居者（短期）→ 物理空间 + 共居活动
  知识社群（长期）→ 内容生产 + 跨城连接
  总部 → 内容 IP + 空间模板输出
```

### 3.2 财务模型

| 项 | 数值 |
|---|---|
| **共居收入** | 100-200 元 / 人 / 天 |
| **空间收入** | 活动场地 + 工作坊 |
| **内容收入** | 知识产品 + 出版 |
| **客单价** | 低频但高客单 |
| **毛利** | 40-50% |
| **扩张速度** | 5+ 城市空间 / 5 年 |

### 3.3 扩张方式

- 慢扩张（每年 1-2 个新空间）
- 每个空间先招募本地主理人
- 主理人共创空间内容 + 运营
- 总部输出方法论 + 品牌

**风险**：
- 物理空间成本高
- 主理人稀缺
- 难规模化

## 四、3 家模式横评

| 维度 | 跳海 | 北辰 | 706 |
|---|---|---|---|
| **核心产品** | 物理空间 + 社交 | 课程 + 社群 | 空间 + 知识 |
| **现金流模型** | 高频低客单（酒） | 中频高客单（课） | 低频中客单（居） |
| **客单价** | 80-150 | 1500-2500 | 300-500 |
| **复购率** | 60%（社交） | 50%（会员） | 30%（居） |
| **扩张速度** | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ |
| **抗风险** | ⭐⭐⭐ | ⭐⭐⭐⭐（线上） | ⭐⭐ |
| **社群黏性** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| **创始人依赖** | 高 | 中 | 低 |

## 五、3 家都做对了的 4 件事

### 5.1 主理人机制

| 品牌 | 主理人角色 | 激励 |
|---|---|---|
| 跳海 | 打酒师 + 店长 | 5-20% 店股份 + 月利润分成 |
| 北辰 | 讲师 + 城市分社 | 课程费分成 + 城市运营权 |
| 706 | 空间主理人 | 内容 IP 共享 + 自治权 |

**主理人是社群核心资产**——激励机制设计决定社群寿命。

### 5.2 内容驱动

| 品牌 | 内容形式 |
|---|---|
| 跳海 | 主题活动 + 调性 |
| 北辰 | 课程 + 工作坊 |
| 706 | 知识生产 + 跨城活动 |

**没有内容，社群只剩空间壳子**。

### 5.3 共创机制

- 跳海：用户当打酒师
- 北辰：用户当讲师 / 活动主理人
- 706：用户当空间主理人

**让用户从"消费者"变"创造者"** —— 这是社群黏性的核心。

### 5.4 价值观统一

三家都强调"价值观"比"商业模式"重要：

- 跳海："让有趣的人找到同类"
- 北辰："让青年有归属感"
- 706："让人与人更近"

**价值观 = 社群识别度**。没有价值观的社群 = 微信群 + 线下聚会。

## 六、3 家都做错了的 / 风险

### 6.1 跳海

- 扩张速度太快 → 质量参差不齐
- 主理人出走风险
- "青年酒馆"形象容易缩水到"普通酒馆"

### 6.2 北辰

- 课程产品同质化
- 城市分社水平不一
- "割韭菜"质疑

### 6.3 706

- 扩张太慢
- 收入规模有限
- 创始人精神依赖强

## 七、3 类用户场景适合哪种

### 7.1 想"快速变现" → 跳海

现金流好，6-12 月回本。**门槛是选址 + 主理人招募**。

### 7.2 想"长期复利" → 706

社群寿命长，但变现慢。**门槛是创始人 IP + 主理人文化**。

### 7.3 想"教育变现" → 北辰

课程可复用，但有"割韭菜"风险。**门槛是讲师资源 + 内容质量**。
