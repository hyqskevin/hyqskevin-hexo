（上）讲活动模式。本篇（中）讲**谁来 + 谁来 + 在哪 + 怎么来**——参与者画像、招募筛选、主理人激励、活动预算、5 个组织工具。

## 一、4 类参与者画像

### 1.1 探索者（30%）

```text
年龄：25-32 岁
职业：互联网 / 自由职业
特征：
  - 刚毕业 1-5 年
  - 迷茫 + 求方向
  - 想"换一种活法"
  - 不满现状 + 想突破
需求：
  - "找到新方向"
  - "找到同类"
预算：低（学生或初级）
```

### 1.2 转换者（40%）

```text
年龄：28-38 岁
职业：中层 / 资深开发 / 中级管理
特征：
  - 工作 5-10 年
  - 想从技术转管理 / 转业务 / 转创业
  - 需要"系统思考框架"
  - 愿意付费学习
需求：
  - "加速职业转换"
  - "找同行支持"
预算：中（年度付费 500-2000 元）
```

### 1.3 创业者（20%）

```text
年龄：30-45 岁
职业：创业者 / 自由职业
特征：
  - 已有 1 个项目（早期）
  - 需要"产品 + 运营 + 心理"支持
  - 关注"思维框架" + "案例"
需求：
  - "找到合伙人 / 投资人"
  - "打磨产品"
预算：高（年度付费 5000+ 元）
```

### 1.4 学者（10%）

```text
年龄：28-40 岁
职业：高校 / 研究院 / 智库
特征：
  - 学术训练背景
  - 关心"严谨方法"
  - 输出导向
需求：
  - "跨界交流"
  - "科普传播"
预算：低（项目经费）
```

## 二、招募与筛选

### 2.1 招募渠道

| 渠道 | 适合 | 转化率 |
|---|---|---|
| 朋友圈 / 微信群 | 探索者 | 中 |
| 知识星球 | 转换者 | 高 |
| 小红书 | 探索者 + 转换者 | 高 |
| 知乎 / 微博 | 学者 | 中 |
| 行业社群互推 | 创业者 | 高 |
| 老校友推荐 | 全部（最准） | 最高 |

### 2.2 筛选流程

```text
申请（在线表单）
  ↓
问卷（10 题筛选动机）
  ↓
视频面试（30 分钟）
  ↓
试参加（1 次活动）
  ↓
决定（双向选择）
```

**关键**：**试参加** > 问卷。问卷能装，回答能背，**试参加才能看出真态度**。

### 2.3 试参加体验

```text
设计原则：
  - 让申请者来 1 次"真实活动"
  - 看是否融入（不强行社交）
  - 听老参与者的真实反馈（不是官方）
  - 给申请者"反选"权利（不适合可走）

避免：
  - 一来就谈钱 / 谈义务
  - 过度热情（让人觉得"必须买"）
  - 强迫"加入"（参与是邀请，不是录取）
```

## 三、主理人激励（不靠钱）

### 3.1 5 种"非钱"激励

```text
1. 身份激励
   "你是 706 主理人"——比"你讲了一场沙龙"强 100 倍

2. 网络激励
   主理人聚会（年度 retreat）——认识同领域顶尖人

3. 成长激励
   主理人 workshop——学演讲 / 学组织 / 学产品

4. 内容激励
   主理人产出（演讲 / 文章）——个人品牌积累

5. 长期激励
   校友网络终身保留——主理人离开后仍是"主理人"
```

### 3.2 主理人成本

```text
直接成本：接近 0
  - 主理人拿的不是钱，是"身份 + 网络 + 成长"

间接成本：
  - 主理人准备时间：5-10 小时 / 周
  - 主理人机会成本：能赚 ¥500-2000 / 场
  - 但身份 + 网络价值远超现金
```

## 四、活动预算

### 4.1 单场小型（10-20 人）

```text
场地：免费 / 共享空间（咖啡馆 / 图书馆）
茶歇：¥300（5 份咖啡 + 小食）
主理人补贴：¥500-1000（车马 + 准备）
物料：¥200
合计：¥1000-1500 / 场
频次：每月 1-2 次
月成本：¥1500-3000
```

### 4.2 季度大型（50-100 人）

```text
场地：¥2000-5000（会议中心 / 写字楼）
茶歇：¥3000（咖啡 + 餐食 + 甜点）
主理人补贴：¥5000-10000（3-5 名主理人）
嘉宾费：¥3000-5000
物料 + AV：¥2000
合计：¥15000-25000 / 场
频次：每季度 1 次
季度成本：¥15000-25000
```

### 4.3 年度成本估算

```text
月小型活动 × 12 = ¥18,000-36,000
季度大型活动 × 4 = ¥60,000-100,000
主理人补贴 × 12 月 = ¥60,000-120,000
场地年租金 = ¥60,000-120,000
其他 = ¥20,000-40,000
年度总成本：¥218,000-416,000
```

## 五、5 个组织工具

### 5.1 金数据 / 麦客

- 活动报名 + 缴费 + 签到 + 反馈一站式
- 国内 SaaS，¥500-2000 / 年

### 5.2 飞书 / 钉钉

- 多维表格管理活动
- 日历预约会议室
- 文档协作

### 5.3 知识星球

- 付费社群 + 直播 + 私信
- 抽成 5%，年费 ¥99-999

### 5.4 Notion / 飞书文档

- 知识库
- 主理人笔记
- 活动记录

### 5.5 小程序自研

- 报名 / 缴费 / 签到 / 直播
- 完全定制（成本高）

**推荐组合**：金数据（报名）+ 飞书（协作）+ 知识星球（社群）+ Notion（知识库）

## 六、3 个月 MVP 启动

### M1：核心团队

```text
3-5 个主理人：
  - 1 统筹（产品 / 运营）
  - 1 学术（哲学 / 心理学）
  - 1 商业（创业 / 投资）
  - 1 工程（AI / 技术）
  - 1 社群（社群运营 / 内容）

试运行 1 个月 → 调整团队配置
```

### M2：首批社群

```text
30-50 人种子社群
  - 来自主理人朋友圈
  - 来自行业社群互推
  - 跑 2-3 场试水活动
  - 收集反馈 + 调整方向
```

### M3：常规化

```text
- 月 1-2 场活动
- 知识星球（付费会员）
- 主理人共创 1 个项目
- 30+ 付费会员 = 月营收 ¥3000+
```
