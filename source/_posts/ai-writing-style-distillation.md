本文回答一个问题：如何学习并蒸馏某人的写作风格和排版，并用智能体写出类似的文章。

Demo 案例以阮一峰（ruanyifeng.com）为示范，完整仿写示例见同系列文档。

## 一、整体框架：两阶段八步法

核心思路分两大阶段，前四步负责"把风格变成文件"，后四步负责"用文件生成文章"。

```text
阶段 A：风格蒸馏（输入：历史文章 → 输出：风格画像文件）
  步骤 1：选 Demo 作者 + 抓语料（5-20 篇）
  步骤 2：多维度提取风格特征
  步骤 3：产出 style.md（可被 LLM 直接读）
  步骤 4：风格验证（盲测 + AI Detector）
                            ↓
阶段 B：AI 仿写（输入：style.md + 主题 → 输出：仿写文章）
  步骤 5：组装 system prompt（风格特征 + 主题 + 字数）
  步骤 6：多模型交叉生成（Claude / GPT-4 / DeepSeek）
  步骤 7：独立判官盲评（剥离作者名打分）
  步骤 8：迭代优化（基于判官反馈调整 prompt）
```

## 二、阶段 A：风格蒸馏

### 2.1 选 Demo 作者与抓语料

**作者选择标准**：

- 风格稳定（10+ 年写作经验）
- 文章多（≥50 篇，最好 100+）
- 文章类型多样（教程、随笔、时评）
- 文风鲜明（有可辨识特征）
- 中文优先（英文圈方法论不通用）

**Demo**：阮一峰（ruanyifeng.com）

**语料规模**：5-20 篇（**5 篇起步**，15-20 篇更佳）

**抓取策略**（避开超时陷阱）：

1. 用 WebSearch 找具体 URL，不抓归档大页面
2. 一次一篇 WebFetch，串行而非并发
3. 每篇正文截断到 2000 字内
4. 30 秒无响应立刻 skip

**抓取字段**：

```json
{
  "title": "...",
  "url": "https://...",
  "date": "YYYY-MM-DD",
  "type": "tech | book | essay | commentary | monthly",
  "content": "纯文本（≤2000字）"
}
```

### 2.2 多维度提取风格特征

**10 个分析维度**：

| # | 维度 | 提取方法 |
|---|---|---|
| 1 | **句法** | 平均句长、句型分布、典型句式 |
| 2 | **段落** | 段长、段首/段尾模式、段落关系 |
| 3 | **词汇** | 高频词、口语/学术混排程度、术语密度 |
| 4 | **排版** | 编号系统、括号、引用块、图表 |
| 5 | **开头模板** | 按文章类型分类（周刊 / 读书 / 时评 / 随笔） |
| 6 | **结尾模板** | 总结型 / 观点型 / 怀旧型 |
| 7 | **情绪基线** | 冷静度、幽默度、煽情度（坐标图） |
| 8 | **修辞** | 反问、比喻、类比、排比的使用频率 |
| 9 | **信息密度** | 事实 / 观点比例、数字精确度 |
| 10 | **不可做清单** | Do/Don't 清单（保留什么、避免什么） |

### 2.3 产出 style.md

**标准格式**（参考风格特征手册）：

```markdown
# {作者名} 写作风格特征手册

## 一、句法特征
（数据表格）

## 二、段落结构
（短段落 + 段首直抛）

## 三、词汇与术语
（口语/学术混搭）

## 四、排版与节奏
（编号系统）

## 五、典型开头模板
（按文章类型）

## 六、典型结尾模板

## 七、情绪基线
（坐标图）

## 八、篇章骨架
（典型文章结构）

## 九、风格坐标
（冷静 ████ / 学究 ███ / 怀旧 ██ ...）

## 十、Do/Don't 清单
```

**关键**：`style.md` 必须能被 LLM 直接读懂，所以用 markdown 表格 + 列表，避免大段散文。

### 2.4 风格验证（盲测 + AI Detector）

**两层验证**：

1. **AI Detector**：用 Pangram / GPTZero 检测原文应得高分（>70% human）
2. **人工盲测**：让独立判官盲评 5 篇原文 + 5 篇仿写，统计准确率

**Demo 结果**（阮一峰）：

- 591 训练样本 → loss 7584→213（97%↓）
- Pangram 评分 50-70% Human（muratcankoylan/book-training 案例）

## 三、阶段 B：AI 仿写

### 3.1 组装 system prompt

**最小可用 prompt 模板**：

```markdown
你是 {作者名}，中国科技博主，风格参考 {作者主页}。

写作要求：
1. 开头用 {开头模板}（如「上周，X」「最近，我读了 X」）
2. 段落 ≤ 4 句，段首直抛论点
3. 编号列表高频使用（一、二、三 + 1、2、3）
4. 第一人称高频（我觉得 / 我认为）
5. 必须用具体数字，不用模糊词
6. 中英混排术语用英文原词
7. 偶尔反问句增强张力
8. 结尾用「总之 / 综上所述 / 我认为」
9. 情绪平和理性，不煽情
10. 段落不超过 5 行

字数：{N} 字左右
主题：{USER_TOPIC}
```

**进阶**：把风格特征手册全文喂进 system prompt，效果更稳定。

### 3.2 多模型交叉生成

**为什么多模型**：

- Claude 偏学术化
- GPT-4 偏结构化
- DeepSeek 偏中文地道
- 同一 prompt 三家生成，质量择优

**Demo**：writer-dna 4 步 pipeline 用 DeepSeek/GLM/Claude/MiniMax 4 模型交叉验证。

### 3.3 独立判官盲评

**判官盲评 SOP**：

1. 把原文 + 仿写混在一起，去掉作者名
2. 让第三方 LLM（或真人）逐篇打分（1-10 分）
3. 维度：句法相似度 / 词汇相似度 / 情感相似度 / 整体像不像
4. 算平均分，>7 分为合格

**Demo**：王建硕 wjs-distilling-style 用 9 轴指纹 + 独立判官盲测，是中文圈最严谨方案。

### 3.4 迭代优化

**迭代 cycle**：

```text
生成 → 盲评 → 发现弱点 → 改 prompt → 再生成
```

**常见弱点 & 对应 prompt 调整**：

| 弱点 | 调整方向 |
|---|---|
| 段落太长 | prompt 加「段落 ≤ 4 句」 |
| 词汇太学术 | prompt 加「口语词如『捣鼓』『挺有料』」 |
| 缺少数字 | prompt 加「必须用具体数字」 |
| 情绪太满 | prompt 加「不煽情不浮夸」 |
| 缺少时间锚点 | prompt 强制「开头必须有时间」 |

## 四、可复用工具箱

| 用途 | 工具 | 备注 |
|---|---|---|
| 抓语料 | WebFetch / WebSearch | 不要用归档大页面 |
| 风格特征提取 | LLM 一次性分析 5-10 篇 | 输出结构化 JSON |
| 仿写生成 | Claude / GPT-4 / DeepSeek | 多模型交叉 |
| 风格验证 | Pangram / GPTZero | AI Detector 测 human 率 |
| 盲评 | 第三方 LLM 或真人 | 关键：剥离作者名 |
| 风格持久化 | skill.md / style.md | 可被任何 agent 读取 |

## 五、伦理与边界（必读）

> **必须告知用户**：
>
> 1. **当代作家禁止克隆**：OpenAI 已禁止为 Stephen King 等当代作家做风格克隆
> 2. **已故作家需谨慎**：版权 + 名誉权 + 家属意愿三重要求
> 3. **"AI 复活亲人"需心理辅导介入**：避免病态哀伤延长
> 4. **明确标注 AI 生成**：仿写文章必须明确「本文由 AI 仿写生成」
> 5. **不得用于伪造演讲 / 伪造声明**：技术中立但应用有边界

## 六、一页纸 Checklist

```text
□ 选好 Demo 作者（10+ 年稳定风格）
□ 抓 5-20 篇语料（时间锚点串行抓取）
□ 提取 10 个维度的风格特征
□ 写出 style.md（结构化，可被 LLM 读）
□ 准备 system prompt（模板 + 风格特征）
□ 多模型生成（至少 3 家）
□ 独立判官盲评（剥离作者名）
□ 迭代优化（基于评分调整）
□ 验证 AI Detector 评分
□ 伦理合规检查（当代作家 / 逝者 / 标注）
```
