```text
宁波正在用「OPC 一人公司」作为 AI 时代产业转型的关键抓手
+ 配套「甬创 9 条」+ 14 个 OPC 社区
```

## 二、3 段式叙事（2025-07 → 2026-08）

### 2.1 惊艳期（2025-07 → 09）

```text
openclaw + hermes 等 Agent 出现
  → 本地社群办 3-4 次学习沙龙
  → 报名火爆（30-50 人 / 场）
  → 2-3 个月后热度骤降
```

**根因**：更新太快 + 学习成本变沉没成本 + 纯技术沙龙覆盖不到泛人群

### 2.2 爆发期（2025-10 → 2026-04）

```text
国内 workbuddy / trae / qcoder / 扣子（带可视化）
+ MCP 协议串联应用
+ 模型编程 / 多模态 / 系统调用大幅提升
+ 各地 AI 比赛（本地办了第一届黑客松）
+ 开发者社群自然生长
```

**关键**：**门槛从"懂技术"降到"会用工具"**——AI 普及的拐点。

### 2.3 政策完善期（2026-05 → 08）

```text
- 创业者意向多但行动少（观望）
- 成功 OPC = 业务 + AI 工具优化（不是从 0 起步）
- 各园区能力不齐（算力 / 运营 / 行业）
- 政府有政策导向但主导性弱
- 制造业基础强但 AI 人才供给不足
```

**核心问题**：**宁波 AI 人才缺口 vs 制造业基础强 = 巨大机会**。

## 三、OPC 一人公司生态

### 3.1 OPC 是什么

```text
OPC = One Person Company
  - 1 个人的公司
  - 用 AI 工具 + 自动化
  - 服务客户 / 做产品
  - 成本接近 0
```

### 3.2 宁波 OPC 现状（2026-08）

```text
14 个 OPC 社区
  - 706 宁波分舵
  - 北辰青年宁波分社
  - 跳海酒馆宁波店
  - 跳动字节（字节系）
  - 等等

"甬创 9 条"政策：
  - 1 人才公寓（3 年免租）
  - 2 创业补贴（最高 30 万）
  - 3 税收减免（3 年）
  - 4 信贷贴息（5% 贴息）
  - 5 子女教育（积分入学）
  - 6 医疗（医保 + 商保）
  - 7 配偶就业
  - 8 父母随迁
  - 9 居留落户
```

### 3.3 4 类典型 OPC 模式

| 模式 | 数量 | 收入区间 | 案例 |
|---|---|---|---|
| AI 工具 / Skill 销售 | 30% | 5-30 万 / 年 | 个人 Skill 包 / 行业 prompt 库 |

## 五、风控模型 3 维重构

### 5.1 传统风控（抵押物驱动）

```text
风控 = 资产 + 流水 + 信用记录
  → 抵押物：房产 / 设备 / 存货
  → 流水：银行账户 / 税务
  → 信用：央行征信
```

### 5.2 新风控（技术信用 + 数字履历 + 生态位势）

```text
风控 = 3 维定价
  1. 技术信用（GitHub / Stack Overflow / 专利）
  2. 数字履历（项目历史 / 客户评价 / 收入流水）
  3. 生态位势（社区地位 / 投资关系 / 媒体曝光）
```

**核心技术信用评估**：

```python
# 示例：评估 OPC 创始人技术信用
def evaluate_tech_credit(person):
    score = 0
    # GitHub 活跃度
    score += min(person.gh_commits * 0.001, 30)  # 最多 30 分
    score += min(person.gh_repos * 0.5, 20)        # 最多 20 分
    score += min(person.gh_stars * 0.005, 20)       # 最多 20 分
    # Stack Overflow
    score += min(person.so_reputation, 15)         # 最多 15 分
    # 专利 / 软著
    score += min(person.patents * 2, 15)            # 最多 15 分

    return min(score, 100)  # 0-100 分
```

### 5.3 评估实例

```text
OPC 创始人 A：
  - GitHub 200 commits / 5 stars → 30 + 2.5 = 32.5
  - Stack Overflow 1000 rep → 15
  - 1 项软著 → 2
  - 总分：49.5 → 中等信用
  → 银行授信 50 万（无抵押）

OPC 创始人 B：
  - GitHub 5000 commits / 200 stars → 30 + 20 + 20 = 70
  - SO 5000 rep → 15
  - 3 项专利 → 6
  - 总分：91 → 高信用
  → 银行授信 500 万（无抵押）
```

## 六、3 类银行业务机会

### 6.1 存款 + 理财

```text
OPC 客户画像：
  - 高收入（30-100 万 / 年）
  - 现金流不稳定（按项目结算）
  - 风险偏好高（创业）

对应产品：
  - 活期 + 短期理财（灵活）
  - 私人银行（高端）
  - 项目分成产品（创新）
```

### 6.2 信贷 + 风控

```text
传统信贷：抵押 / 流水
OPC 信贷：技术信用 / 数字履历
  → 10-100 万小额信贷（高频）
  → 30-90 天短期周转（匹配项目周期）
  → 知识产权质押（无固定资产）
```

### 6.3 投行 + 生态

```text
- 政府引导基金跟投
- 创投联动（VC + 银行）
- 知识产权 ABS（资产证券化）
- 跨境结算（外贸 / 出海 OPC）
```
