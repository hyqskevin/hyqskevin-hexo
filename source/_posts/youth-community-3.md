（上）讲了 C2B 模式，（中）讲了三家各自模式。本篇（下）把三家共性提炼成**可复用方法论**——任何人想建一个青年社群，都能从这里找到参考。

## 一、3 阶段落地路径

```text
阶段 1：种子期（0-6 月）
  └─ 找 5-10 个核心主理人
  └─ 每周 1 次线下活动
  └─ 验证社群黏性

阶段 2：生长期（6-18 月）
  └─ 主理人扩到 20-50
  └─ 月活动 4-8 次
  └─ 商业模型探索（酒馆 / 课程 / 空间任一）

阶段 3：扩张期（18+ 月）
  └─ 选 1-2 个城市开分店 / 分社
  └─ 主理人授权机制（股份 / 分成）
  └─ 品牌 / 价值观标准化
```

每阶段有 1 个**必达指标**：
- 种子期：核心 10 人连续 3 个月每周出现
- 生长期：月活 100+，月留存 50%+
- 扩张期：第二家店 / 分社自给自足

## 二、5 件必做的事

### 2.1 找到 3-5 个"主理人候选"

主理人画像：
- 在你的目标群体中有**社交枢纽**地位
- 有**内容输出能力**（写 / 讲 / 拍）
- 对社群有**长期投入意愿**（不是 3 个月热情）

**找法**：
- 现有社群挖（活动参与者 → 主理人）
- 内容平台挖（公众号 / 知乎 / B 站的中 V）
- 线下场景挖（读书会 / 行业聚会 / 兴趣小组）

### 2.2 找到"价值观锚点"

价值观不是口号，是**用户筛选标准**。问自己：
- 我们**不为**什么？（筛选掉不合适的用户）
- 我们**为**什么？（吸引合适的用户）
- 什么行为**会被劝退**？（保持社群纯粹）

跳海："装腔作势的人不欢迎" → 筛选出真性情的青年
北辰："想走捷径的人不欢迎" → 筛选出愿意思考的青年
706："来镀金的人不欢迎" → 筛选出真探索的青年

### 2.3 设计主理人激励

| 激励 | 跳海 | 北辰 | 706 |
|---|---|---|---|
| 现金 | 利润 5-20% | 课程费分成 | 空间营收分成 |
| 股权 | 5-20% 店 | 分社股权 | 内容 IP 共享 |
| 自治权 | 主理人定调 | 课程自主 | 空间完全自治 |
| 培训 | 总部培训 | 教学培训 | 主理人学院 |

**设计原则**：**主理人收入 ≥ 当地最低工资 2 倍**，否则没人愿意干。

### 2.4 选对"现金流产品"

不要上来就做高客单（会员 / 课程），**先用高频低门槛拉流量**：

- 跳海：先酒馆 → 后"打酒师"机制 → 最后课程
- 北辰：先免费活动 → 后小额付费 → 最后年费会员
- 706：先共居活动 → 后内容产品 → 最后空间

**现金流产品排序**（推荐）：
1. 线下活动（5-50 元 / 人，低门槛拉人）
2. 体验型消费（酒馆 / 咖啡）
3. 内容订阅（99-499 元 / 年）
4. 高客单课程（1000+ 元 / 人）
5. 物理空间（年费会员制）

### 2.5 重视"线下"而非"线上"

- 跳海 30+ 家酒馆（全是线下）
- 706 5+ 城市空间（全是线下）
- 北辰虽然有线上课，但 80% 收入来自线下

**线上是连接工具，线下是社群基础**。跳过线下做线上社群 = 微信群。

## 三、主理人激励设计 5 步法

### 3.1 第一步：找 3-5 个种子主理人

- 不给钱先合作 3 个月
- 看 ta 们是否真的投入
- 通过 3 个月的筛选后保留 2-3 个核心

### 3.2 第二步：设计 0-1 元激励

- 完成活动 → 报销 100-500 元成本
- 招募新人 → 50-200 元 / 人奖金
- 简单粗暴，看 ta 愿不愿意为钱做事

### 3.3 第三步：设计 5-20% 利润分成

- 主理人负责的内容 / 活动 / 空间，营收的 5-20% 归 ta
- 每月结算，透明
- 跳海的"打酒师"模式就是这个

### 3.4 第四步：设计股权 / 期权（成熟期）

- 单店 / 单社的 5-20% 股权
- 4 年 vesting，1 年 cliff
- 防止主理人拿了股份就走

### 3.5 第五步：设计自治权（长期）

- 主理人对自家店的"调性"有完全决定权
- 不必事事请示总部
- 总部只管：品牌 / 培训 / 财务

## 四、创始人"去中心化"路径

### 4.1 阶段 1：强中心化（0-1 年）

```text
创始人 100% 决定：
  - 选什么活动主题
  - 选什么主理人
  - 怎么宣传
  - 怎么分钱
```

**必要性**：早期没有强中心，社群会乱。

### 4.2 阶段 2：半中心化（1-2 年）

```text
创始人决定 50%：
  - 战略 / 价值观 / 品牌
  - 重大人事（主理人更换）

主理人决定 50%：
  - 单店 / 单社运营
  - 主理人激励设计
```

### 4.3 阶段 3：弱中心化（2+ 年）

```text
创始人 0%（真正退场）：
  - 只在理事会 / 顾问角色
  - 季度出席

主理人决定 100%：
  - 全部运营决策
  - 通过主理人委员会自治
```

**跳海 vs 706 差异**：
- 跳海：创始人梁二狗强控制（每家店都深度介入）→ 难去中心化
- 706：弱中心化（每个空间主理人完全自治）→ 创始人离开仍能运转

**你的目标**：让创始人能"走开"，社群还在活。

## 五、给本地社群的 5 阶段建议

### 阶段 1：种子期（0-6 月）

**任务清单**：
- [ ] 找到 3-5 个核心主理人
- [ ] 每周 1 次线下活动
- [ ] 价值观锚点 + 筛选标准
- [ ] 简单的报名表（收集信息）
- [ ] 微信群（运营核心阵地）

**目标**：核心 10 人连续 3 个月每周出现

### 阶段 2：产品化（6-12 月）

**任务清单**：
- [ ] 主理人激励 0-1 元 → 5% 利润分成
- [ ] 第一个现金流产品（活动 / 体验）
- [ ] 内容沉淀（公众号 / 知识库）
- [ ] 数据追踪（谁参加 / 谁消费 / 谁传播）

**目标**：月营收 5 千-5 万，找 PMF

### 阶段 3：扩张期（12-24 月）

**任务清单**：
- [ ] 选 1-2 个城市开分店 / 分社
- [ ] 主理人股权 / 期权设计
- [ ] 品牌 / 价值观标准化
- [ ] 总部 + 地方双层结构

**目标**：第二家店 / 分社自给自足

### 阶段 4：成熟期（24-36 月）

**任务清单**：
- [ ] 创始人退到"主理人委员会"角色
- [ ] 标准化 SOP（开店 / 招聘 / 培训）
- [ ] 引入职业经理人
- [ ] 准备下一轮融资 / 退出路径

**目标**：能脱离创始人运转

### 阶段 5：品牌期（36+ 月）

**任务清单**：
- [ ] 从"社群品牌"升级"生活方式品牌"
- [ ] 出版 / 影视 / IP 衍生
- [ ] 输出价值观（白皮书 / 行业报告）
- [ ] 行业标准制定

**目标**：成为"青年文化"代名词

## 六、3 条避坑

1. **不要追估值**：估值高 = 退出压力 = 社区感稀释
2. **不要做平台**：平台 = 监管 + 责任 = 重资产
3. **不要上市**：上市 = 季报压力 = 短期主义

跳海、北辰、706 都没上市 / 没融资大钱，**这是它们能保持社区感的关键**。

> **三篇核心洞察**：**社群商业化的本质是"让用户服务用户"（C2B）**。三家估值差异反映的是现金流模型，不是社群质量。**真正可复用的方法论是"主理人机制 + 内容驱动 + 共创"**。宁波 / 杭州本地社群不用复制某家，**找到自己的主理人 + 价值观 + 现金流产品** 就能起跑。
